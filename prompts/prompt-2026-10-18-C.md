## Established domain conventions (from the Nachtrag — same OCR engine/source)
- **☉** (circle-dot) = "der Orden" (the Order). OCR mangles it as `(`, `Q`, `O`, or drops it. Restore as ☉ where the scan shows it.
- **▢ / ▢▢** (hollow square) = "Loge"/"Logen" (lodge/lodges). Keep symbol as printed, don't silently normalize.
- **"III."** is almost always a misread of **"Ill."** (Illuminatus).
- **f/ſ** (long-s) confusion is the single most common OCR error — fix silently (not itemized).
- **Redacted names via dashes/equals** (e.g. "V===", "S==") are a REAL printed convention in these documents — preserve them, don't guess identities.
- **"x."-dot notation** (e.g. "M.x.x.", "R.x.") = Masonic raised-dot abbreviation (∴). Keep as printed.
- **Diagrams** (recruitment pyramid, hierarchy trees) become noise in OCR — describe them in prose in the corrected text rather than transcribing garbage.
- **French/other-language quotations** — transcribe as legible, flag as not independently verified.
- **Page-end catchwords and signature marks are NOT part of the text** — don't include them.
- **Silent whole-word omission is a real OCR failure mode** — watch for it against the scan.

## Working method (page-by-page) — the proven pipeline
1. **Bound your range:** your pages are **105–144** (physical PDF page numbers). Grab the corresponding raw-OCR text from the transcription file. NOTE: the transcription has NO page markers — locate each page's text via `pdftotext -f N -l N <pdf> -` or by reading the transcription sequentially (its line order follows page order).
2. **Render the scan:** for each page `N` in your range:
   `pdftoppm -f N -l N -r 300 -png <pdf> /tmp/<agent>_page_N`
   (24 cores available; renders are fast and parallel-safe.)
3. **Read the rendered page image directly** (you have vision). Compare it against the raw-OCR text for that page.
4. **Write corrections:** append the corrected text to `..._corrected.txt` under a `--- PDF page NNN ---` marker; log content-level changes in your per-agent log.
5. **Commit in batches** (every ~20–30 pages, or whenever a coherent slice is done) so work is never lost:
   `git add -A && git commit -m "correct main volume pp. N-M (Phase 3, prompt-2026-10-18-C)"`
   Work in the repo root: `/mnt/data/projects/Research/illuminati_translation_project`.
